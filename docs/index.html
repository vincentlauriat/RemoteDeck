// why it exists// pourquoi elle existe

One client instead of threeUn client au lieu de trois

Reaching a remote Mac meant juggling Apple Remote Desktop, heavy and built for fleets, and Screen Sharing, which has no library and no tabs; Claude computer use desktops needed yet another VNC client. RemoteDeck is the one fast, keyboard-friendly app for all of them, with its own RFB/VNC library written in Swift.Atteindre un Mac distant, c'était jongler entre Apple Remote Desktop, lourd et pensé pour les parcs, et le Partage d'écran, sans bibliothèque ni onglets ; les bureaux Claude computer use demandaient encore un autre client VNC. RemoteDeck est l'app rapide, pensée pour le clavier, qui couvre tout, avec sa propre bibliothèque RFB/VNC écrite en Swift.

privacy & securityconfidentialité et sécurité

What leaves your Mac, and whenCe qui quitte votre Mac, et quand

No account, no analytics, no tracker — on this page either. The app talks only to the places below.Pas de compte, pas de mesure d'audience, pas de traceur — sur cette page non plus. L'app ne parle qu'aux destinations ci-dessous.

  • The machines you addLes machines que vous ajoutez — sessions, Test connection, and a TCP probe every 60 s for the ones you mark Watch (no credentials sent by the probe).sessions, test de connexion, et une sonde TCP toutes les 60 s pour celles marquées « Surveiller » (la sonde n'envoie aucun identifiant).
  • Bonjour — on your local network, only while the Discovery Panel is open.sur le réseau local, seulement quand le panneau Découverte est ouvert.
  • Anthropic — only when you use the Claude Assistant, with your own API key: your prompt and screenshots of that session. Nothing is cached on disk.seulement quand vous utilisez l'assistant Claude, avec votre propre clé d'API : votre demande et les captures de cette session. Rien n'est mis en cache sur le disque.
  • GitHub — Sparkle's daily update check, and Help / What's New when you open them.la vérification quotidienne des mises à jour (Sparkle), et l'Aide / les Nouveautés quand vous les ouvrez.
  • What a request carriesCe que porte une requête — to GitHub, only the standard User-Agent (app name and build, CFNetwork and Darwin versions): no identifier, no cookie, nothing cached on disk.vers GitHub, seulement le User-Agent standard (nom et build de l'app, versions de CFNetwork et de Darwin) : aucun identifiant, aucun cookie, rien en cache sur le disque.
  • iCloud — your Machine Library (private CloudKit database) and passwords (iCloud Keychain), if you turn sync on.votre bibliothèque (base CloudKit privée) et vos mots de passe (Trousseau iCloud), si vous activez la synchronisation.
  • Keychain onlyTrousseau uniquement — machine passwords and the API key are never written to the library, logs or CloudKit records.les mots de passe et la clé d'API ne sont jamais écrits dans la bibliothèque, les journaux ou CloudKit.
  • Unencrypted protocolProtocole non chiffré — RFB is not encrypted beyond the authentication exchange: use your LAN or a VPN. A connection that reaches a public Internet address stops and asks first, then shows an "Internet" badge with the clipboard off.RFB n'est pas chiffré au-delà de l'échange d'authentification : utilisez le réseau local ou un VPN. Une connexion qui atteint une adresse Internet publique s'arrête et demande d'abord, puis affiche un badge « Internet », presse-papiers coupé.
  • No downgradePas de repli — a Mac with a user name must offer Apple authentication; a configured password never falls back to no authentication.un Mac avec un nom d'utilisateur doit proposer l'authentification Apple ; un mot de passe configuré ne retombe jamais sur « aucune authentification ».
  • Confirmed actionsActions confirmées — the Claude Assistant never clicks or types without your Confirm, and pauses after 8 turns without one.l'assistant Claude ne clique ni ne tape jamais sans votre confirmation, et se met en pause après 8 tours sans action confirmée.
  • Sandbox — App Sandbox and Hardened Runtime, signed with a Developer ID and notarized by Apple.App Sandbox et Hardened Runtime, signée avec un Developer ID et notariée par Apple.
